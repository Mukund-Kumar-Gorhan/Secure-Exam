# 🔐 Secure Exam System

A full-stack **online examination platform** with built-in anti-cheating features, user authentication, and real-time result evaluation.

---

## 🚀 Features

* 🔑 User Signup & Login (Authentication)
* 🧠 Randomized Question System
* ⏱️ Countdown Timer
* 🚫 Anti-Cheating Protection

  * Tab switch detection (auto submit)
  * Copy/Paste disabled
  * DevTools blocked
* 📊 Instant Result & Score Calculation
* 🗄️ SQLite Database Integration
* ⚙️ Admin Panel (View Users & Results)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** SQLite
* **Security:** bcrypt, express-session

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```
git clone https://github.com/YOUR_USERNAME/secure-exam.git
cd secure-exam
```

---

### 2️⃣ Install Dependencies

```
npm install
```

---

### 3️⃣ Run Server

```
node server.js
```

---

### 4️⃣ Open in Browser

```
http://localhost:3000
```
